## MINI SPEC DU SITE:

- Des PDG d'entreprises de +100 employés 
- Francophones (limiter les buzzwords marketing et les anglicismes)
- Intérêt pour l'IA mais non technophiles (0 jargon technique).

### FORMAT DU SITE : 

- Style: professionnel, moderne. Design system: https://fr.ippon.tech
- Structure: 1 écran = 1 message clé. 
- Règles éditoriales :
  - Réduire les textes longs en phrases courtes.
  - Ton : PDG à PDG, sobre, direct, crédible.
  - Préférer : concret, usage, recul, responsabilité, arbitrage, sérénité, leadership. -- Ne pas utiliser : "révolutionnaire", "disruptif", "game changer".
  - Chaque écran doit avoir :
    - 1 titre fort
    - 1 phrase d’explication
    - éventuellement 3 points maximum (densité faible)
  - Contenu: très clair à comprendre (pas de jargon technique)
- Responsive.

---

### TECHNOLOGIE :

- Contraintes de code : 1 seul fichier HTML.
  - CSS dans une balise <style>.
  - JavaScript dans une balise <script>.
  - Aucune base de données.
  - Aucun framework.
  - Aucun CDN.
  - Aucun asset externe obligatoire.
  - Code commenté uniquement quand utile.
  - Noms de classes lisibles et cohérents.
  - JS limité aux interactions nécessaires : menu mobile, formulaire, navigation, affichage page/section, éventuel modal vidéo.
- Application stricte des bonnes pratiques de coding (architecture, DRY, YAGNI...).
- Hébergement : Repo GitHub > Coolify > VPS Hostinger.
